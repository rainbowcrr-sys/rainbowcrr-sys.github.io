Install / 安装

Get up and running
in 5 steps

English

  1. Download the latest search-enhancer-vX.Y.Z.zip from Releases
  2. Unzip the folder
  3. Open chrome://extensions (or edge://extensions)
  4. Enable Developer Mode
  5. Click Load unpacked → select the unzipped folder

中文

  1. 从 Releases 下载最新 search-enhancer-vX.Y.Z.zip
  2. 解压文件夹
  3. 打开 chrome://extensions（或 edge://extensions）
  4. 开启右上角 开发者模式
  5. 点击 加载已解压的扩展程序 → 选择解压后的文件夹
